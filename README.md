# 📚 Study Planner

A simple and interactive web application designed to help students organize their study tasks and track their daily progress.

## ✨ Features

* Create and organize study tasks
* Mark tasks as completed using checkboxes
* Simple and user-friendly interface
* Styled with CSS

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript (if used in the project)

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Start organizing your study tasks.

## 🎯 Purpose

This project was created to improve web development skills and help students manage their study activities.
